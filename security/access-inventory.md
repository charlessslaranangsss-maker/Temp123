# Current access inventory
Static public pages and local checklist have no database dependency. POST /api/contact validates bounded JSON, exact Origin, App Check and verified app ID, shared rate limits and idempotency before private persistence. POST /api/deliver requires a fixed scheduler bearer secret, takes at most five queued jobs and uses leases/provider idempotency. All client Firestore access is denied. No customer authentication, sessions, tenants, public admin, uploads, payments or analytics exist. No Storage bucket is configured. Operator access requires Google IAM. No real database or contact service is deployed; provider configuration remains blocked.
