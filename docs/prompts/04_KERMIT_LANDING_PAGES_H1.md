# Prompt 4 — Kermit landing pages and mixed-H1 playbook

Copy everything below into a new development task and fill in the bracketed inputs.

> Create or improve **one approved landing-page batch** for [REPOSITORY], [DOMAIN], [FAMILY], [EXACT URL LIST], and [CITY/STATE DATA]. Before editing, inspect `AGENTS.md`, protected URL register, assigned pages, live/preview behavior, relevant real inventory photos, and existing pages for duplication. First classify each page by the real search intent and family: base camp/man camp, mobile kitchen, modular dishwashing, refrigeration; on a verified multi-service site choose other actual inventory families such as shower, restroom combination, laundry, or sleeper when those are the page's subject. Do not put `mobile kitchen` in every Temporary123 city H1.
>
> Use this mixed-H1 formula, in this order: **City, State + commercial use case + equipment family + rental intent.** Example only for a genuine shower page: `Port Angeles, Washington Industrial Basecamp Shower Trailer Rental`. Use one stable H1 per page and a natural phrase, not a keyword bucket. A multi-service hub may need a broader facility H1; do not promise one piece of equipment then show another. Align SEO title/meta, opening paragraph, equipment specifications, local logistics, commercial applications, FAQs and CTA, internal links, and image/alt text with the H1's actual promise. Keep the topical equipment + facility need + rental intent coherent throughout. Human review must approve each family template.
>
> Write for commercial/institutional customers such as prisons, hospitals, nursing homes, man camps, hotels, military sites and industrial facilities—not homeowners, small businesses or tourists. Local logistics must be real and relevant, not generic sightseeing. Verify product specs and local facts; if uncertain, flag them, do not invent them. Treat the 22-ft shower trailer with three sinks as a distinct verified flagship when relevant, separate from shower/restroom combinations. Use matching model photographs only; interior images before exterior in service galleries; no-photo state when absent. Vary suitable commercial backgrounds without misrepresenting actual units. Alt text is truthful and descriptive.
>
> Clarify the boss's “300–550 keywords maximum” before using it as a numeric production rule. If he means 300–550 **words per page**, use it as a flexible editorial range and prioritize substance. If he means a **site-wide keyword list**, create a deduplicated research/mapping sheet, not hundreds of phrases per page. Never add 300–550 repeated keywords to one landing page or create doorway pages. The content must be useful, accurate, distinct and natural.
>
> For high-value Ahrefs pages, preserve the exact existing URL/slug and original topic where practical; do not casually 301 valuable pages to a generic destination. Check HTTP 200, production indexability, self-referencing canonical, sitemap, internal links and content. Put location pages under locations, equipment under services, information under articles/resources. Record all evidence in the owner-visible register. The first 25 list is an **inventory until each page is rebuilt and verified**. Request individual GSC indexing only after production readiness and approval; that request does not guarantee indexing. Stage roughly 200–1,000 **finished and reviewed** pages per four-day release only if quality and crawl/index signals warrant it. Gradual publishing is monitoring, not a way to bypass Google's spam policies. Pause on significant crawl, duplication, canonical, or quality issues.
>
> Deliver the mapping table (URL → topic → family → exact H1 → title → primary intent → photo source → owner), approved sample pages, QA results and missing-fact list before bulk generation. Test each sample at phone/desktop and its exact URL, metadata, canonical, links, image match, sitemap presence and actual status. Do not push, deploy, or change indexing directives until URL mapping and release are approved.

## H1 review card for the 15–20 minute team training

1. Identify the page's real commercial customer, equipment and rental action.
2. Assemble `City, State + commercial use case + equipment family + rental intent` as one readable H1.
3. Check title/meta, introduction, details, logistics, applications, FAQs/CTA, internal links, and photos against it.
4. Remove unverified claims, wrong-family images, tourist copy and repetitive keywords.
5. After publication, verify the live exact URL, H1, canonical, sitemap, rendering and functional CTA; record evidence.
