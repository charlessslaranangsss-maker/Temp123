These are specifications, **not completion claims**. Verify current code, data, deployment, and live behavior before reporting completion.

Keep the boss's “300–550 keywords maximum” phrase as written in the landing-page brief. It is not permission to stuff hundreds of repeated phrases onto a page. Review each proposed page for useful, accurate, distinct content and natural keyword use.
